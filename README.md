## 📋 Description

**IMPACT - PC** est un site e-commerce professionnel dédié à la vente d'ordinateurs, d'accessoires et d'imprimantes à Madagascar. Le site permet aux visiteurs de parcourir les produits, de consulter les détails, et de contacter directement le vendeur via WhatsApp ou Messenger.

---

## ✨ Fonctionnalités

### Côté Visiteur (Client)
- 🏠 Page d'accueil avec hero section moderne
- 🛍️ Boutique avec liste des produits
- 🔍 Barre de recherche et filtres (catégorie, marque)
- 📱 Fiche produit détaillée avec carrousel d'images (5 max)
- 💬 Contact direct via WhatsApp et Messenger
- 📞 Page contact avec Google Maps

### Côté Admin (Gestion)
- 🔐 Espace admin sécurisé (JWT + bcrypt)
- 📊 Tableau de bord avec statistiques
- ➕ Ajouter / Modifier / Supprimer des produits
- 🖼️ Upload d'images (fichier local ou URL)
- 🔑 Changement de mot de passe sécurisé

---

## 🛠️ Technologies Utilisées

### Front-End
- **HTML5** — Structure
- **CSS3** — Style et animations
- **Bootstrap 5** — Framework responsive
- **JavaScript (DOM)** — Interactions dynamiques
- **Font Awesome** — Icônes
- **Google Fonts (Poppins)** — Typographie

### Back-End
- **Node.js** — Environnement serveur
- **Express.js** — Framework web
- **SQLite** — Base de données légère
- **Multer** — Upload de fichiers
- **bcryptjs** — Hachage des mots de passe
- **JWT (jsonwebtoken)** — Authentification sécurisée
- **CORS** — Sécurité des requêtes
- **dotenv** — Variables d'environnement
